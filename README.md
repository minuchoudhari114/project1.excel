## 🧠 Excel Functions Implemented

### 1️⃣ Logical Functions

Used for decision-making and automatic classification.

`IF()` · `Nested IF()` · `AND()` · `OR()`

**Example:**
```excel
=IF(H2>=80,"Excellent","Good")
```

### 2️⃣ Conditional Calculations

Used to analyze data based on specific conditions.

`COUNTIF()` · `COUNTIFS()` · `SUMIF()` · `SUMIFS()` · `AVERAGEIFS()`

**Example:**
```excel
=COUNTIF(C2:C21,">60")
```

### 3️⃣ Lookup & Reference Functions

Used to search and retrieve information dynamically.

`VLOOKUP()` · `XLOOKUP()` · `XMATCH()` · `INDEX()` · `MATCH()`

**Example:**
```excel
=VLOOKUP(F2,$A$2:$B$6,2,FALSE)
```

### 4️⃣ Text Functions

Used to extract, combine, and format text.

`LEFT()` · `LEN()` · `FIND()` · `TEXT()` · `CONCATENATE()` · `UPPER()`

**Example:**
```excel
=UPPER(B2)
```

### 5️⃣ Date & Time Functions

Used to calculate years, dates, and employee service periods.

`TODAY()` · `YEAR()` · `MONTH()` · `DAY()` · `DATEDIF()`

**Example:**
```excel
=IF(E2>TODAY(),0,DATEDIF(E2,TODAY(),"Y"))
```

### 6️⃣ Mathematical Functions

Used for totals, averages, rounding, and comparisons.

`SUM()` · `AVERAGE()` · `ROUND()` · `MAX()`

**Example:**
```excel
=ROUND(AVERAGE(C2:E2),2)
```

### 7️⃣ Dynamic & Advanced Functions

Used for flexible references and automatic data filtering.

`INDIRECT()` · `OFFSET()` · `FILTER()`

**Example:**
```excel
=FILTER(A2:H21,H2:H21>80,"No students")
```
